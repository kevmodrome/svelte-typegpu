# Asset World models

These nine unmodified GLB files are from **Nature Kit (2.1)** by Kenney.

- Source: https://kenney.nl/assets/nature-kit
- Archive: https://kenney.nl/media/pages/assets/nature-kit/37ac38a37b-1677698939/kenney_nature-kit.zip
- License: CC0 1.0, included in `License.txt`.
- Original paths: `Models/GLTF format/<filename>`.

Only the campsite's models are bundled. They use static triangles and material
color factors, with no external textures or runtime third-party requests.
The asset regression test verifies every primitive is imported, bounds are finite,
and the combined file-size budget stays below 150 KB.
